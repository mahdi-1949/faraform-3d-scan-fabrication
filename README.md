# فرافُرم | اسکن سه‌بعدی و ساخت قطعه

وب‌سایت نمونه‌کار فرافُرم برای معرفی خدمات اسکن سه‌بعدی، مهندسی معکوس، نمونه‌سازی و ساخت قطعه.

## صفحات

- صفحه اصلی: `index.html`
- خدمات: `services.html`
- روند همکاری: `process.html`
- نمونه‌کارها: `projects.html`
- درباره ما: `about.html`
- تماس: `contact.html`
- پرسش‌های متداول: `faq.html`
- پرونده‌های پروژه: `case-housing.html`، `case-inspection.html`، `case-prototype.html`

تمام فایل‌های CSS، JavaScript و favicon در پوشه `assets/` قرار دارند. این مخزن برای انتشار مستقیم با GitHub Pages آماده شده است.
